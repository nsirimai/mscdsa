# Source PDF Register

This directory contains the original PDF sources used to construct the policy and public-sentiment corpora for the dissertation on the policy--practice gap in AI-in-education governance.

The register contains **73 original source documents**: **56 policy documents** and **17 original sentiment documents**. Because the corpus contains a large number of sources, citing every corpus document individually in the methodology would be impractical. This README therefore provides a single, comprehensive source register from which readers can identify and open the documents used in the study.

The names shown below are **human-readable document titles taken from the source text in the corpus**, rather than repository filenames. Repository filenames are used only as the targets of the PDF links. Where a cleaned document did not preserve a complete title page, the shortest descriptive title supported by the document text is used.

> **Evidence boundary.** Synthetic sentiment is not included in this PDF register because it is auxiliary generated material rather than original source evidence. Synthetic and original sentiment remain separately identifiable throughout the analytical workflow.

## Reproducibility and citation note

The corpus identifiers above are retained during preprocessing and chunk construction, providing a stable connection between each source PDF and the processed text used in subsequent analyses.

This register is intended to document corpus provenance and make the complete source collection accessible to the reader. Where the dissertation makes a substantive claim that depends on a particular publication, the corresponding scholarly, governmental, institutional, or media source is still cited in the dissertation text. The README avoids repeating repository filenames as document titles and instead presents the source titles represented in the corpus.
